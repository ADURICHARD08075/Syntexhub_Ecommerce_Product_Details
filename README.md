# E-commerce Product Details Page

This project is a UI/UX design for an E-commerce Product Details Page created as part of the Syntexhub internship task.

## Project Overview
The goal of this project is to design a clean, user-friendly product details page that improves product discovery and conversion for users.

## Features
-## Features
- Product image gallery with multiple views
- Image zoom interaction for detailed viewing
- Product title, price, and description
- Size and color variants using components & variants
- Clear primary and secondary CTA buttons
- Add-to-cart micro-interaction with confirmation modal
- Message Seller button for direct buyer–seller communication
- Dedicated Message Seller screen for easy inquiry
- Responsive designs for both mobile and desktop
